# biotech-data-analysis
I created this computational pipeline as a sophomore at TJHSST to assess the WDBC dataset's morphological predictors of malignancy. This project showcases my ability to extract multivariate features and find important diagnostic biomarkers using Python (Pandas/Seaborn). I identified particular morphological thresholds that function as primary indicators for oncology classification by visualizing high-dimensional metadata using correlation matrices and distribution plots. In order to close the gap between unprocessed clinical data and useful medical intelligence, this study focuses on the sensitivity and specificity of nuclear radius and texture. The repository demonstrates my capacity to create repeatable data pipelines and produce analytics fit for publication in a formal research environment. To guarantee strict data integrity, industry-standard libraries were used for all statistical wrangling and clustering analyses.

Technical Stack: Python 3.14.0, Pandas, Seaborn, Matplotlib
